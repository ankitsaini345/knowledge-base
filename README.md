# Second Brain

A personal knowledge management system built using Markdown, GitHub, and Obsidian.

This repository serves as my single source of truth for:

- Software Engineering
- Node.js & React
- AI & Agentic Systems
- System Design
- Cloud & DevOps
- Interview Preparation
- Career Growth

The goal is to continuously convert conversations, research, projects, and experiences into structured, reusable knowledge that can be reviewed, updated, and eventually used as the foundation for a personal AI assistant.
